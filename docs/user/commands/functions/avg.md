# Average

`avg`

The `avg` command will take the average of the top N numbers on the stack, stopping once a non-number is encountered or the stack is empty.

---

### Function Arguments

```plaintext
avg(n1, n2, ...)
```

---

### Algebraic Example

```plaintext
avg(1, 2, 3)
```

### RPN Example

```plaintext
1
2
3
avg
```
